Customer Segmentation & Campaign Analytics Dashboard:-

This repository contains an end-to-end marketing analytics project that segments customer data and evaluates campaign performance through an interactive Streamlit dashboard. The project analyzes demographic traits, spending behaviors, purchasing channels, and campaign responsiveness to help businesses optimize their marketing strategies.

🚀 Features:-

Demographic Segmentation: Classifies customers by age groups, income brackets, marital status, and number of children.

Product-Wise Spending Analysis: Tracks expenditures across key product categories (e.g., Wines, Fruits, Meat, Fish, Sweets, and Gold).

Channel Classification: Compares purchasing behaviors across different shopping channels (Web, Catalog, Store, and Direct Visits).

Campaign Response Tracking: Evaluates customer conversion rates and responsiveness across multiple marketing campaigns.

Interactive Streamlit Dashboard: Provides dynamic filters and interactive charts to explore data insights in real time.
